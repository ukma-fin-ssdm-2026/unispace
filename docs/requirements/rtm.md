# Матриця простежуваності вимог (RTM)

Цей документ візуалізує зв'язок між користувацькими історіями, системними вимогами та тестовими сценаріями системи бронювання UniSpace. Він створений для контролю якості та підтвердження того, що кожна заявлена вимога реалізована в коді й покрита відповідними перевірками.

## Легенда маркувань
- **US (User Story):** Користувацька історія.
- **FR:** Функціональна вимога (Functional Requirement).
- **NFR:** Нефункціональна вимога (Non-Functional Requirement). Категорії NFR:
  - **PERF:** Продуктивність (Performance).
  - **REL:** Надійність (Reliability).
  - **SEC:** Безпека (Security).
  - **USAB:** Зручність використання (Usability).
- **TC / PT / ST / UT:** Ідентифікатори тестів (Test Case, Performance Test, Security Test, Unit Test).
- **TBD / Планується:** Етап визначення або написання тесту.
