# Вихідний код API

У зв'язку з архітектурним рішенням нашої команди розділити систему на ізольовані проєкти (окремо Backend та Frontend на Django), вихідний код API знаходиться у директорії [`/Backend/api/`](../../Backend/api/).

Ця папка (`src/api/`) залишена для збереження стандартної структури репозиторію, яка вимагається в описі лабораторних робіт, проте фактична розробка та генерація OpenAPI відбуваються у спеціалізованому модулі бекенду.
